# Port inventory

`JSON_AS_PORT_INVENTORY.tsv` is the exhaustive, machine-readable inventory. It contains one
row for every copied source/config file and uses only these dispositions:

- **port** — adapt in place with algorithmic fidelity.
- **algorithm donor** — retain useful control-flow or packed-operation ideas at
  an existing json-ty seam rather than activate the upstream module.
- **already implemented** — json-ty already owns an equivalent kernel.
- **unsupported** — depends on UTF-16/GC/container/object-layout facilities
  outside json-ty's current document domain.
- **deferred** — useful for a later naive/SIMD or dispatch phase.

The original entry-point family and the planned UTF-8/document signature are
recorded per row. Signatures are deliberately descriptive rather than frozen
APIs; byte bounds, document destinations, writer state, and result-header errors
are the invariant requirements.
